# 通知・権限・検索条件

## 1. 前提

本資料は、DCIMの通知、権限、検索条件に関する要件を整理したものです。

---

## 2. 通知要件

## 2.1 通知一覧

| 通知ID | 通知名 | 通知内容 | 通知タイミング | 通知対象 | 優先度 |
|---|---|---|---|---|---|
| N-001 | 保守期限60日前通知 | 保守契約の終了日が60日後に近づいたことを通知する | 保守終了日の60日前 | テナント管理者、運用管理者、編集者、保守契約連絡先 | 必須 |
| N-002 | 保守期限30日前通知 | 保守契約の終了日が30日後に近づいたことを通知する | 保守終了日の30日前 | テナント管理者、運用管理者、編集者、保守契約連絡先 | 必須 |
| N-003 | 保守期限当日通知 | 保守契約の終了日当日であることを通知する | 保守終了日当日 | テナント管理者、運用管理者、編集者、保守契約連絡先 | 必須 |
| N-004 | 保守期限切れ通知 | 保守契約が期限切れになったことを通知する | 保守終了日の翌日以降 | テナント管理者、運用管理者、編集者、保守契約連絡先 | 必須 |
| N-005 | プラン上限接近通知 | 利用数が上限に近づいたことを通知する | 使用率80%以上 | テナント管理者、契約管理者 | 必須 |
| N-006 | プラン上限到達通知 | 利用数が上限に到達したことを通知する | 上限到達時 | テナント管理者、契約管理者 | 必須 |
| N-007 | ユーザー招待通知 | ユーザー招待メールを送信する | 招待時 / 再招待時 | 招待対象ユーザー | 必須 |
| N-008 | 操作エラー通知 | 外部連携や一括取込の失敗を通知する | エラー発生時 | テナント管理者、実行者 | 重要 |

## 2.2 通知チャネル

| チャネルID | チャネル | 初期対応 | 備考 |
|---|---|---|---|
| NC-001 | 画面通知 | 対応する | ログイン後の通知一覧、ダッシュボード表示 |
| NC-002 | メール通知 | 対応する | 初期必須。保守期限、招待、パスワード再設定、上限通知、エラー通知で利用 |
| NC-003 | Slack / Teams通知 | 将来対応 | 外部連携要件として検討 |
| NC-004 | Webhook通知 | 将来対応 | Enterprise向け候補 |

## 2.3 通知設定

| 設定ID | 設定項目 | 初期値 | 変更可否 |
|---|---|---|---|
| NS-001 | 保守期限通知日数 | 60日前 | 変更可 |
| NS-002 | 追加通知日数 | 30日前、当日、期限切れ | 変更可 |
| NS-003 | 通知対象ロール | テナント管理者、契約管理者、運用管理者、編集者 | 変更可 |
| NS-004 | メール通知ON/OFF | ON | 変更可。初期リリースから対応 |
| NS-005 | 画面通知ON/OFF | ON | 原則ON |

## 2.4 通知対象者モデル

| 対象種別 | 初期対応 | 方針 |
|---|---|---|
| ロール宛通知 | 対応する | テナント内の対象ロールに属する有効ユーザーへ画面通知・メール通知を送信する |
| 個別ユーザー宛通知 | 対応する | 招待対象ユーザー、操作実行者など明示されたユーザーへ送信する |
| 保守契約連絡先宛通知 | 対応する | 保守契約に紐づく外部連絡先へメール通知できる。画面通知はシステム利用者のみ対象とする |
| 外部Webhook宛通知 | 将来拡張 | Slack / Teams / Webhook連携時に検討する |

外部連絡先へ送信する通知は、保守期限通知に限定する。プラン上限、権限変更、操作エラーなどの管理系通知はシステム利用者ロール宛を基本とする。

## 3.3 権限制御方針

| 項目 | 方針 |
|---|---|
| 認証 | Spring Securityによるログイン認証を想定 |
| 認可 | ロールベースアクセス制御を基本とする |
| テナント分離 | ユーザーは所属テナントのデータのみ参照可能 |
| 削除操作 | 物理削除ではなく論理削除を基本とする |
| 初期テナント管理者 | テナント初期作成時に登録されるテナント管理者は通常のユーザー削除・無効化不可。解約フローでのみ利用停止扱いにできる |
| 最低限監査情報 | 主要エンティティに作成者、作成日時、更新者、更新日時を保持する |
| 操作履歴 | 初期開発では主要な登録、更新、削除、招待、権限変更、プラン変更の操作履歴を保存し、テナント管理者・監査担当者が検索・閲覧できる。変更差分を含む完全な変更履歴は将来拡張とする |

## 4.3 検索仕様

| 項目 | 仕様 |
|---|---|
| 文字列検索 | 部分一致を基本とする |
| 大文字小文字 | 区別しない方針 |
| 別名検索 | 正式名称と同じ検索対象に含める |
| タグ検索 | 複数タグ指定を可能とする |
| 削除済みデータ | 通常検索では対象外とする |
| 検索結果CSV出力 | 初期必須。対象プランや出力範囲の詳細はプラン要件で定義する |
