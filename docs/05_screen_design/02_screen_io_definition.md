# 画面項目・入出力定義書

## 1. 目的

本書は、DCIM（Data Center Asset & Infrastructure Manager）の各画面について、画面モックだけでは不足しやすい「表示項目」「入力項目」「検索条件」「ボタン・リンク」「入出力」「権限制御」「遷移」を定義する。

画面実装、詳細設計、テストケース作成時は、本書を画面単位の仕様根拠として参照する。

## 2. 対象範囲

- 対象画面: `SCR-001`〜`SCR-041`、および `SCR-001A`〜`SCR-001C`
- 画面一覧: `docs/03_basic_design/01_screen_list.md`
- 画面モック一覧: `docs/05_screen_design/01_screen_mock_list.md`
- HTMLモック: `docs/05_screen_design/mocks/`

## 3. 共通方針

### 3.1 共通表示項目

| 区分 | 表示項目 | 備考 |
|---|---|---|
| 共通ヘッダー | サービス名、ログインユーザー名、ロール、通知アイコン、ログアウト | 未認証画面ではログインユーザー情報を表示しない |
| 共通サイドメニュー | ダッシュボード、各管理メニュー、設定、通知、操作履歴 | ロール・権限により表示制御する |
| 共通フッター | バージョン、コピーライト、問い合わせ導線 | モック上は簡略表示可 |
| 共通メッセージ | 成功、警告、エラー、入力補助 | Vaadin Notification / Dialog を想定 |
| 共通パンくず | 上位カテゴリ、画面名 | 詳細・登録編集画面で表示する |

### 3.2 一覧画面の共通入出力

| 区分 | 項目 |
|---|---|
| 入力: 検索条件 | キーワード、状態、タグ、対象カテゴリ固有条件、ページ番号、表示件数、ソート項目、ソート方向 |
| 出力: 一覧 | ID、名称、状態、更新日時、カテゴリ固有項目、操作 |
| ボタン | 検索、条件クリア、新規登録、詳細、編集、削除、CSV出力、ページング |
| 遷移 | 詳細画面、登録・編集画面、関連画面 |
| 権限制御 | 表示、登録、編集、削除、CSV出力を個別権限で判定する |

### 3.3 詳細画面の共通入出力

| 区分 | 項目 |
|---|---|
| 入力 | 画面遷移元から渡される対象ID |
| 出力 | 基本情報、状態、関連情報、タグ、作成日時、更新日時、作成者、更新者 |
| ボタン | 編集、削除、一覧へ戻る、関連画面へ遷移、CSV出力（対象画面のみ） |
| 権限制御 | 閲覧権限がない場合は表示不可。編集・削除は権限により非表示または非活性 |

### 3.4 登録・編集画面の共通入出力

| 区分 | 項目 |
|---|---|
| 入力 | 新規登録時は入力値、編集時は対象IDと更新値 |
| 出力 | 初期表示値、選択肢、入力エラー、保存結果 |
| ボタン | 保存、キャンセル、戻る、削除（編集時・権限ありの場合） |
| バリデーション | 必須、桁数、形式、重複、上限、参照整合性、権限 |
| 遷移 | 保存成功時は詳細または一覧へ遷移。キャンセル時は遷移元へ戻る |

### 3.5 共通エラー表示

| 種別 | 表示方針 |
|---|---|
| 入力エラー | 対象項目直下にメッセージを表示し、画面上部にもサマリを表示する |
| 権限エラー | 403相当のメッセージを表示し、許可された画面へ戻す |
| 対象なし | 削除済み・存在しない対象として一覧へ戻す導線を表示する |
| 競合 | 更新競合として再読み込みまたは編集やり直しを促す |
| システムエラー | 詳細を出さず、問い合わせ用のエラーIDを表示する |

## 4. 画面別定義

### SCR-001 ログイン画面

| 区分 | 定義 |
|---|---|
| 主な利用者 | 全ユーザー |
| 表示項目 | ロゴ/サービス名、メールアドレスまたはログインID、パスワード、ログイン状態保持、ログイン失敗メッセージ、パスワード再設定リンク |
| 入力項目 | メールアドレスまたはログインID、パスワード、ログイン状態保持フラグ |
| ボタン・リンク | ログイン、パスワードを忘れた場合、招待メールからの初回設定導線 |
| 入力チェック | ID必須、パスワード必須、アカウント有効性、ロック状態、認証失敗回数 |
| 出力・結果 | 認証成功時はロール別初期画面へ遷移。失敗時は理由を過度に特定しないエラーを表示 |
| 遷移 | 成功: SCR-002 または SCR-039。再設定: SCR-001A |

### SCR-001A パスワード再設定依頼画面

| 区分 | 定義 |
|---|---|
| 主な利用者 | 未認証ユーザー |
| 表示項目 | メールアドレス入力欄、再設定案内、送信完了メッセージ、ログイン画面へ戻るリンク |
| 入力項目 | メールアドレス |
| ボタン・リンク | 再設定メール送信、ログイン画面へ戻る |
| 入力チェック | メール形式、必須。存在有無を画面上で推測させない |
| 出力・結果 | メール送信依頼受付結果。対象が存在しない場合も同一文言で完了表示 |
| 遷移 | SCR-001、メールリンク経由でSCR-001B |

### SCR-001B 新パスワード設定画面

| 区分 | 定義 |
|---|---|
| 主な利用者 | 未認証ユーザー |
| 表示項目 | トークン検証結果、新パスワード、確認用パスワード、パスワードポリシー、期限切れ/使用済み/不正トークンエラー |
| 入力項目 | 新パスワード、確認用パスワード、トークン（URLパラメータ） |
| ボタン・リンク | パスワード設定、再設定依頼へ戻る、ログイン画面へ戻る |
| 入力チェック | トークン有効性、有効期限、使用済み判定、パスワードポリシー、一致確認 |
| 出力・結果 | 設定完了メッセージ、ログイン画面への誘導 |
| 遷移 | SCR-001、SCR-001A |

## 5. 権限制御の実装単位

| 操作 | 制御方針 |
|---|---|
| 画面表示 | 画面ごとの閲覧権限で判定する |
| 検索 | 閲覧権限がある範囲のデータのみ検索対象にする |
| 新規登録 | 登録権限とプラン上限を満たす場合のみ表示・有効化する |
| 編集 | 編集権限がない場合は非表示または非活性にする |
| 削除 | 削除権限、配下データ有無、監査要件を満たす場合のみ許可する |
| CSV出力 | CSV出力権限、個人情報/機密情報マスキング方針、ロール制限で判定する |
| 詳細遷移 | 遷移先画面の閲覧権限を満たす場合のみリンクを表示する |
