# 画面一覧

## 1. 目的

本書は、Data Center Asset & Infrastructure Manager の基本設計における画面一覧を定義する。

対象は、データセンター、ラック、機器、IPサブネット、保守契約、クラウドリソース、ユーザー・権限、契約プラン管理を含む。

## 2. 画面一覧

| 画面ID | 画面名 | 主な利用者 | 概要 | 主な機能 |
|---|---|---|---|---|
| SCR-001 | ログイン画面 | 全ユーザー | システムへのログインを行う | メールアドレス/IDログイン、パスワード入力、ログイン失敗表示 |
| SCR-002 | ダッシュボード | 全ユーザー | 管理対象の概要を確認する | DC数、ラック数、機器数、サブネット数、保守期限アラート表示 |
| SCR-003 | データセンター一覧 | 管理者、運用者、閲覧者 | 登録済みデータセンターを一覧表示する | 検索、絞り込み、新規登録、詳細遷移 |
| SCR-004 | データセンター詳細 | 管理者、運用者、閲覧者 | データセンター情報を確認・編集する | 基本情報、所在地、連絡先、建物/フロア一覧表示 |
| SCR-005 | データセンター登録・編集 | 管理者、運用者 | データセンター情報を登録・更新する | 正式名称、別名、地域、都道府県、連絡先、タグ登録 |
| SCR-006 | 建物・フロア一覧 | 管理者、運用者、閲覧者 | DC配下の建物・フロアを管理する | 建物、フロア、エリアの一覧・追加・編集 |
| SCR-007 | ラック列一覧 | 管理者、運用者、閲覧者 | フロア/エリア単位でラック列を管理する | ラック列検索、ラック本数表示、利用状況表示 |
| SCR-008 | ラック一覧 | 管理者、運用者、閲覧者 | ラックを一覧表示する | ラック名、U数、設置場所、空きU数、機器数表示 |
| SCR-009 | ラック詳細 | 管理者、運用者、閲覧者 | ラック内の搭載状態を確認する | ラック搭載図、機器配置、空きU、搭載機器一覧 |
| SCR-010 | ラック登録・編集 | 管理者、運用者 | ラック情報を登録・更新する | ラック名、別名、U数、ラック列、タグ登録 |
| SCR-011 | ラックテンプレート一覧 | 管理者、運用者 | ラックテンプレートを管理する | テンプレート一覧、作成、複製、削除 |
| SCR-012 | 機器一覧 | 管理者、運用者、閲覧者 | サーバー/NW機器を一覧表示する | 種別、設置場所、IP、保守有無、タグ検索 |
| SCR-013 | 機器詳細 | 管理者、運用者、閲覧者 | 機器の詳細情報を確認する | 基本情報、設置ラック、IP、保守契約、タグ表示 |
| SCR-014 | 機器登録・編集 | 管理者、運用者 | 機器情報を登録・更新する | 正式名称、別名、種別、ラック位置、IP、保守契約ひもづけ |
| SCR-015 | IPサブネット一覧 | 管理者、運用者、閲覧者 | IPサブネットと配下IPの利用状況を管理する | CIDR別表示、空き/利用中検索、機器ひもづけ |
| SCR-016 | IPサブネット登録・編集 | 管理者、運用者 | IPサブネット情報を登録・更新する | CIDR、用途、配下IP利用状況、ステータス、タグ登録 |
| SCR-017 | 保守契約一覧 | 管理者、運用者、閲覧者 | 保守契約を一覧表示する | 契約期限、ベンダー、対象機器、期限切れ検索 |
| SCR-018 | 保守契約詳細 | 管理者、運用者、閲覧者 | 保守契約詳細と対象機器を確認する | 契約情報、対象機器一覧、期限、通知設定 |
| SCR-019 | 保守契約登録・編集 | 管理者、運用者 | 保守契約を登録・更新する | 契約名、ベンダー、開始日、終了日、対象機器ひもづけ |
| SCR-020 | 保守未設定機器一覧 | 管理者、運用者 | 保守契約未設定の機器を抽出する | 未設定機器検索、契約ひもづけ、CSV出力 |
| SCR-021 | 保守期限アラート一覧 | 管理者、運用者 | 保守期限が近い契約を確認する | 2か月前通知対象、期限切れ、対応状況管理 |
| SCR-022 | クラウドアカウント一覧 | 管理者、運用者、閲覧者 | AWS等のクラウドアカウントを管理する | アカウント、リージョン、リソース数表示 |
| SCR-023 | クラウドリソース一覧 | 管理者、運用者、閲覧者 | EC2/EKS/コンテナ等を一覧表示する | 種別、リージョン、アカウント、タグ検索 |
| SCR-024 | クラウドリソース詳細 | 管理者、運用者、閲覧者 | クラウドリソースの詳細を確認する | インスタンス情報、リージョン、タグ、関連機器表示 |
| SCR-025 | タグ管理画面 | 管理者、運用者 | タグを管理する | タグ作成、編集、削除、利用件数表示 |
| SCR-026 | 通知設定画面 | 管理者 | 通知条件と通知先を管理する | 保守期限通知、メール通知先、通知タイミング設定 |
| SCR-027 | ユーザー一覧 | 管理者 | テナント内ユーザーを管理する | ユーザー招待、権限変更、無効化 |
| SCR-028 | ユーザー登録・編集 | 管理者 | ユーザー情報を登録・更新する | 氏名、メール、ロール、ステータス設定 |
| SCR-029 | 権限ロール一覧 | 管理者 | ロールと権限を確認する | ロール別権限表示、編集可否確認 |
| SCR-030 | 契約プラン・利用状況画面 | 管理者 | 現在のプランと利用上限を確認する | DC数、ラック数、機器数、IP数、ユーザー数、オプション利用数表示 |
| SCR-031 | オプション追加画面 | 管理者 | サブネット・機器追加オプションを管理する | サブネット10件単位、機器100台単位の追加 |
| SCR-032 | 監査ログ画面 | 管理者 | 操作履歴を確認する | 操作ユーザー、対象、操作種別、日時検索 |
| SCR-033 | システム設定画面 | 管理者 | テナント全体設定を管理する | 表示設定、検索条件初期値、デフォルト通知設定 |

## 3. 画面分類

| 分類 | 対象画面 |
|---|---|
| 認証 | SCR-001 |
| ダッシュボード | SCR-002 |
| データセンター管理 | SCR-003〜SCR-006 |
| ラック管理 | SCR-007〜SCR-011 |
| 機器/IP管理 | SCR-012〜SCR-016 |
| 保守契約管理 | SCR-017〜SCR-021 |
| クラウド管理 | SCR-022〜SCR-024 |
| 共通マスタ | SCR-025 |
| 通知・権限・設定 | SCR-026〜SCR-033 |

## 4. 備考

- 画面はVaadinによるサーバーサイドUIを想定する。
- 一覧画面は原則として検索条件、ページング、ソート、CSV出力を備える。
- 登録・編集画面は新規登録と編集を同一画面または同一Viewクラスで実装する。
- 契約プラン上限に到達した場合は、登録ボタンを非活性または警告表示とする。
