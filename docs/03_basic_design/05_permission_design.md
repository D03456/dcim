# 権限設計

## 1. 目的

本書は、Data Center Asset & Infrastructure Manager のユーザー権限、ロール、操作可否を定義する。

## 2. 基本方針

- テナント単位でユーザーとデータを分離する。
- Spring Securityを利用し、画面表示およびサービス実行時に権限チェックを行う。
- 最小権限の原則に従う。
- 監査ログに主要操作を記録する。

## 3. ロール定義

| ロールID | ロール名 | 概要 |
|---|---|---|
| ROLE_TENANT_ADMIN | テナント管理者 | 契約、ユーザー、権限、全データを管理できる |
| ROLE_OPERATOR | 運用者 | DC、ラック、機器、IP、保守契約を登録・編集できる |
| ROLE_VIEWER | 閲覧者 | 登録データを閲覧できる。更新は不可 |
| ROLE_BILLING_ADMIN | 契約管理者 | 契約プラン、利用状況、オプションを管理できる |
| ROLE_AUDITOR | 監査閲覧者 | 監査ログと設定を閲覧できる |

## 7. データアクセス制御

| 制御項目 | 内容 |
|---|---|
| テナント分離 | ログインユーザーのtenantIdと対象データのtenantIdが一致する場合のみアクセス可 |
| 管理者操作 | ユーザー追加、権限変更、通知設定、契約設定は管理系ロールのみ可 |
| 更新操作 | 閲覧者は登録、編集、削除、CSVインポート不可 |
| 削除操作 | 主要データの削除は管理者または運用者のみ可。論理削除を原則とする |
| 監査ログ | 管理者と監査閲覧者のみ閲覧可 |

| 契約プラン・オプション変更 | 操作者、変更内容、日時 |
| 通知設定変更 | 操作者、変更内容、日時 |
